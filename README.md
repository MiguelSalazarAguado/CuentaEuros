# CuentaEuros
Juego web educativo e interactivo diseñado para enseñar a niños y personas con discapacidad intelectual a contar, sumar y familiarizarse con el uso de monedas y billetes de Euro.

Introducción

CuentaEuros es una aplicación web interactiva diseñada para enseñar de forma visual y lúdica el manejo del sistema monetario europeo (euros y céntimos). Está desarrollada íntegramente con HTML, CSS y JavaScript (Vanilla), lo que permite su ejecución directa en cualquier navegador web de escritorio sin necesidad de instalaciones ni dependencias externas.

El objetivo principal de esta herramienta es servir como apoyo educativo en aulas, hogares y centros de educación especial, transformando el aprendizaje matemático en una experiencia interactiva y libre de frustraciones.
